# TXT 阅读器（alpha.19）

TXT 阅读器从 alpha.19 开始提供；alpha.18 及之前的 APK 不包含此功能。完整发布前验证见 [alpha.19 报告](reports/alpha19.md)。

## 使用

1. 在书库选择 **导入 PDF / TXT**，选择 `.txt` 文件。
2. 选择编码。默认自动识别 BOM，然后严格尝试 UTF-8，失败后尝试 GB18030；也可指定 UTF-8、UTF-16LE、UTF-16BE、GB18030 或 GBK。无 BOM 的编码识别不是绝对可靠；如有乱码，请重新导入并选择正确编码。不同的显式编码不会覆盖正在使用的旧快照。
3. 使用 **上一页 / 下一页**、页码输入及 **跳转** 阅读；也可用左右方向键（输入框、选择器操作不受影响）。
4. **章节**目录支持中文“第…章/卷/节”、序章、序言、楔子、尾声、后记，以及英文 `Chapter 1` / `Chapter IV` 等短标题。目录来自文本行启发式识别，不保证识别所有自定义标题；无章节时仍可按页码跳转。
5. 调整 **字号**（12–32），或切换 **显示原文**。平板等宽屏（视口至少 768 CSS 像素）采用**左侧原文、右侧译文，逐段对齐**；窄屏保持上下排列。隐藏原文时恢复居中单栏。布局切换不改变内容分页、句子 ID 或翻译缓存。退出重开保留页码、字号、原文开关和页内滚动位置；调整字号时尽量保留当前正文锚点。
6. 翻译操作复用已有的手动、当前页、邻页及全篇翻译能力。已有合格译文会恢复；书库也可启动全部翻译、暂停和继续。若只想看原文，可开启顶部 **只阅读**（PDF/TXT 通用）：不显示译文、不触发翻译，也不需要加载模型；关闭后缓存仍可使用。详见[只阅读模式](reading-only.md)。

## 分页与存储

- TXT 使用独立的纯文本 WebView 入口，不转成 PDF、不加载 PDF.js、不申请存储目录的广泛访问权限。
- 导入时复制到 App 私有空间，输出规范化 UTF-8 快照；保留正文字符，仅移除文件开头编码 BOM，并统一 CRLF/CR 为 LF。
- 内容页最多 4,000 个 UTF-16 单元，尽量在换行处切开，章节从新内容页开始。**这是固定内容分页，页内可滚动，不是按屏幕高度重排的纸张分页。** 字号或横竖屏变化不会改变翻译分页及断点。
- 单个原始 TXT 最大 64 MiB；规范化 UTF-8 最大 192 MiB；最多 100,000 页、10,000 个识别章节。超限明确拒绝，不会静默截断。
- 用稳定页/块/句 ID 复用现有队列、缓存和全篇断点协议。文本分页版本属于文档 revision，不改动现有 PDF 或共享译文的全局缓存指纹。
- 文件索引包含页范围和校验和；打开时验证，缺失或损坏时从私有 UTF-8 快照重建。导入、索引校验和读页在 IO 线程执行，前端仅保留有限页状态。
- 章节通过有界桥消息分批获取，正文按页获取；纯文本均使用 `textContent` 渲染。
- TXT 不显示 PDF 专属的画笔批注及“另存批注 PDF”。书库删除只删除该文档的私有副本和索引，外部原文件、其他文档和共享译文保留。
- 无数据库清空或 schema 迁移。格式依据不可变的私有快照路径，而非用户可重命名的标题。

## 验证与边界

TXT 初轮及左右分栏检查（加入只阅读之前）：Core 91 项（90 通过、1 项可选真实模型测试跳过），App 18 项通过，Web/上游契约共 83 项通过，TypeScript 通过；Lint 0 错误、53 警告。实际桌面 Edge 已验证 TXT 翻页、目录跳转、字号/锚点、重开恢复、缓存恢复、手机宽度布局、平板左右分栏与隐藏原文后单栏恢复，以及后台保存屏障；现有 PDF 后台流程也通过实际 PDF.js 小样本回归。详见 [TXT 阶段验证记录](reports/txt-reader-validation.json)；加入只阅读后的集成验证另见[只阅读验证记录](reports/reading-only-validation.json)。

- 核心单元测试覆盖编码、换行、长行、Unicode、分页和章节、索引损坏/重建及二进制/空白拒绝。
- App 单元测试覆盖格式判断不受重命名影响、TXT 不加载 PDF 草稿以及 PDF 增量尾部读取保持原样。
- Web 单元测试和桌面浏览器测试覆盖 TXT 状态与渲染；`npm run test:text-reader` 使用实际生成的 Web 资源和浏览器，但 Native 桥、存储和译文均是模拟实现，不是 Android 设备或模型推理测试。
- 新增 TXT 阅读器尚需真实 Android 手机/平板验收，尤其是中文编码、超长小说、软键盘、全屏、旋转及系统回收后的恢复。
