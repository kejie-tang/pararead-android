# alpha.19 — TXT、只阅读与阅读器控件

版本：`0.2.0-alpha.19`，versionCode **19**。增量基于公开 alpha.18 源码 `b233fdc62711f16f00346b2279e6e75c6c255909`；旧标签和发布附件保持不变。

## 内容

- 独立 TXT 入口：有界解码、自动/显式编码、规范化私有 UTF-8 快照、校验索引、稳定分页与章节。TXT 身份按格式/编码隔离，PDF 历史身份不变。原始输入上限 64 MiB，内容页最多 4,000 UTF-16 单元，不按屏幕高度重新分页。
- TXT 页码/目录跳转、12–32 字号、阅读锚点、缓存/重试和持久后台全篇翻译。至少 768 CSS 像素时原文左、译文右，逐段对齐；窄屏上下排列，隐藏原文后单栏。
- PDF/TXT 只阅读：原文展示、无前台推理或译文缓存恢复，不改变翻译配置；保留进度、PDF 批注/导出和既有缓存。明确启动的书库后台翻译独立运行。
- 模式切换等待阅读状态及必要的批注保存确认后再重开；失败保留原会话/编辑。失败保存仅清理匹配事务的私有暂存，不影响已发布草稿和其他事务。
- TXT/Web 和原生 Compose 操作栏圆角分组、主次操作、浅深色、焦点与触控尺寸。PDF 只增加装饰，不修改 PDF.js 工具栏尺寸。错误保持低调灰色、无红色波浪线、纯文本诊断及重试。
- 未改变 Room schema、模型引擎、提示词或共享缓存指纹；不清库、不删除旧文档或有效译文。

使用说明：[TXT](../txt-reader.md) · [只阅读](../reading-only.md)。

## 证据边界

- 浏览器里的 Native 桥、存储、译文和保存故障是受控模拟，PDF.js 与生成 Web 资源为实际实现；不是 Android 真机截图、系统回收验收或模型质量证据。原生 Compose 控件编译通过，Web 截图不展示该原生栏。
- 本次没有 Android instrumentation 执行、模拟器/实体设备运行、真实模型推理/下载或整篇论文实测。历史版本的设备/模型结果不冒充本次结果。
- 早期 [TXT](txt-reader-validation.json)、[只阅读](reading-only-validation.json) 和 [UI](reader-ui-polish.json) 报告保留各阶段范围；最终打包检查以本报告为准。
- 本文件记录本地发布前检查；远程 CI 和签名工作流另外在待发布提交上执行各自门禁，只有成功后才公开新版本。

## 签名与升级

公开 APK 必须是 `org.pararead.android`、ARM64、versionCode **19**，并通过 v2 签名验证；保留已有预览证书 SHA-256：

```text
e044c8f329f42465866add4d041f29c498009361241610c8ee2de43ae6e87a45
```

此持久预览证书身份为 Android Debug，不宣称正式生产签名。签名由既有 GitHub Environment 工作流处理，不读取或输出密钥。签名 APK 下载后再次验证版本、证书、对齐、许可、原创示例和生成 reader 资源；校验 SHA256SUMS 后才公开草稿，再验证匿名下载。

相同签名可直接覆盖旧预览版，保留私有 PDF/TXT、批注、缓存、模型和进度。**不要为绕过签名错误卸载或清除数据。** 本次无数据迁移/清空。
