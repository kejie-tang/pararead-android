# 只阅读模式（alpha.19）

PDF/TXT 只阅读从 alpha.19 开始提供；alpha.18 及之前的 APK 不包含此功能。完整发布前验证见 [alpha.19 报告](reports/alpha19.md)。

## 使用

- 打开 PDF 或 TXT，在阅读器顶部开启 **只阅读**。该偏好会记住，并用于之后打开的 PDF/TXT；关闭开关回到原有翻译模式。全屏时先退出全屏即可切换。
- 切换会重新打开当前阅读器：先保存最新阅读位置和未落盘的 PDF 批注，等待原生存储确认后，再停止旧会话的翻译、等待推理资源释放，并按阅读进度加载。保存失败时保持原模式及原阅读器，不丢弃内存中的批注。它不是清空文档或删除缓存。
- **只阅读与手动翻译不同**：手动模式仍可显示缓存译文、点击句子翻译；只阅读只显示原文，不恢复译文、不自动翻译、也不响应翻译或逐句重试操作。
- PDF 保留原文页面、翻页、缩放、阅读进度、全屏、批注和批注导出，不创建翻译侧栏或选句连线。
- TXT 保留原文、翻页、页码/章节跳转、字号、阅读进度及全屏；不显示双语分栏、原文对照开关或“翻译当前页”。原文空白和换行保留。
- 只阅读不要求加载本地模型，不调用模型或翻译 API。退出只阅读后，原有合格译文缓存、双语显示偏好和翻译范围仍然保留。

## 全篇翻译与缓存

- 只阅读会话不会自动续跑全篇翻译，不写入新的翻译任务检查点，也不清除既有全篇翻译游标。关闭只阅读后按现有恢复规则继续。
- 这是**前台阅读显示选项**，不改变翻译配置指纹。书库中用户明确启动的“全部翻译”仍属于独立后台操作，不受前台只阅读偏好禁用。
- 模式切换先等待 `reading.saved` 和必要的 `save.finished`，再经既有取消/等待/会话隔离屏障关闭旧会话。已确认且未变化的 PDF 批注不会重复写草稿，避免不必要地改变文档 revision。原生主机和 Web 桥均禁止只阅读会话发起翻译，避免仅隐藏按钮却继续推理。
- 不清库、不迁移数据库，也不删除缓存、PDF 批注或 TXT 私有文本快照。

## 验证与边界

- 只阅读开发阶段：Core 共 94 项，93 通过、1 项可选真实模型测试跳过；App 18 项通过。Web/上游契约共 118 项通过，TypeScript 通过；后续 UI 美化后的 120 项及完整打包检查见 alpha.19 报告。
- Android 主代码、资源及 AndroidTest 编译通过；Lint 0 错误、41 警告。**AndroidTest 仅编译，未执行设备测试。**
- 实际 Edge 使用生成的 TXT/PDF 阅读器资源，验证只阅读无翻译/译文缓存请求、阅读功能保留、切回缓存恢复、实时位置保存、PDF 批注保存成功及失败后的继续操作；PDF 使用 887 字节原创两页夹具。既有 PDF 后台流程亦通过 869 字节两页夹具回归。
- 单元/契约测试覆盖保存确认顺序、并发 autosave 等待、超时/迟到确认隔离、未变化批注不重复写草稿，以及失败保存事务清理。后者的原生受控 IO 失败用例已编译，但未在设备执行。
- 详情：[结构化验证记录](reports/reading-only-validation.json)。

浏览器检查中的 Native 桥、存储、保存故障和译文均为模拟实现。它们不能替代真实 Android 手机/平板、真实模型和系统回收/旋转验收。此处的只阅读开发阶段证据不含 APK 组装或签名；alpha.19 的完整打包与发布流程另见上述报告。
