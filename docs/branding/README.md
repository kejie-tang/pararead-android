# ParaRead Android icon

Original vector artwork created for this project: two facing pages with aligned lines represent reading the source and translation together. Uses the app palette and contains no third-party artwork or fonts. Distributed under the project Apache-2.0 license.

`app-icon.svg` is the project/web version. Android uses the matching adaptive vector in `app/src/main/res/`, including a monochrome version for themed launchers. Launcher masks are applied by Android.
